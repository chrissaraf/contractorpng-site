# Μαθήματα της εφαρμογής

Η μνήμη του κιτ για αυτή την εφαρμογή. Ο συντονιστής **τη διαβάζει πριν από κάθε εργασία** και **γράφει μία γραμμή
μετά από κάθε εργασία** που έμαθε κάτι: τι δούλεψε, τι απέτυχε, ποιος agent βοήθησε, τι να μην ξαναγίνει.
Νεότερη πρώτη. Μόνο γνώση για τον τρόπο δουλειάς, ποτέ δεδομένα πελατών, ποσά ή κλειδιά.
