# Πρωτόκολλο συνεργασίας agents

Ισχύει για κάθε agent (Claude Code, Base44 Superagent) και για κάθε άνθρωπο που αγγίζει αυτό το repo.
Σκοπός: καμία διπλή δουλειά, καμία σύγκρουση, πάντα ένα καθαρό επόμενο βήμα.

## Όριο ευθύνης

| Ρόλος | Κάνει | Δεν κάνει |
|---|---|---|
| Claude Code | Κώδικα, tests, πάντα σε branch με PR | Deploy, production ρυθμίσεις, τιμολόγηση |
| Base44 Superagent | Deploy, έλεγχοι υγείας, CI, back-ups, ενημέρωση `docs/STATE.md` | Δεν ξαναγράφει κώδικα που συντηρεί ο Claude Code |
| Χρήστος | Λογαριασμοί, κλειδιά, domain, νομικά, αποφάσεις | — |

## Πηγές αλήθειας

1. Το repo. Όχι τα chats, όχι τα αντίγραφα.
2. `docs/STATE.md` — κατάσταση σε λίγες γραμμές. Διαβάζεται πρώτο.
3. `README.md` — τι είναι το προϊόν και τι δεν είναι.

## Κανόνες

1. Ένα branch ανά εργασία: `agent/<θέμα>-<ημερομηνία>`. Ποτέ δύο agents στο ίδιο branch.
2. Το `main` μένει πράσινο. Κάθε αλλαγή κώδικα περνά από PR με tests.
3. Πριν γράψεις κώδικα, διάβασε `docs/STATE.md`. Αν η δουλειά υπάρχει ήδη, μη την ξαναρχίσεις.
4. Μην αλλάξεις ό,τι λέει το «Μην αλλάξεις» στο `STATE.md` (ζωντανές ρυθμίσεις, ονόματα υπηρεσιών, μεταβλητές).
5. Στο τέλος κάθε εργασίας, ενημέρωσε το `docs/STATE.md`: τι άλλαξε, τι μένει, ποιος το έχει.
6. Καμία νέα λειτουργία εκτός «Επόμενο βήμα» του `STATE.md` χωρίς απόφαση.
