## Τι είναι
Το δημόσιο site της Contractor PNG (συντήρηση, επισκευή, αναβάθμιση κτιρίων), Astro, δημοσιεύεται στο GitHub Pages. Τελείως ξεχωριστό από την εφαρμογή.

## Κατάσταση
- Ζωντανό: https://contractorpng.gr (17/11/2026).
- 21/11/2026: νέο λογότυπο-σπιτάκι (ίδιο με την εφαρμογή) σε κεφαλίδα, favicon, εικονίδια και εικόνα κοινοποίησης, σε PR. Ζωντανό μόλις γίνει merge.
