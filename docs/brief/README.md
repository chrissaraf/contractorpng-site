# Brief εφαρμογής (πρότυπο)

Το γράφει ο συντονιστής μετά τη συζήτηση με τον χρήστη και το εγκρίνει ο χρήστης. Μία σελίδα.

```markdown
# <Όνομα εφαρμογής> · brief · ηη/μμ/εεεε
**Σε μία πρόταση:** <τι κάνει και για ποιον>
**Ποιοι τη χρησιμοποιούν:** <ρόλοι, πόσοι, από κινητό ή υπολογιστή>
**Πρόβλημα που λύνει:** <τι γίνεται σήμερα και γιατί δεν αρκεί>
**Πρώτη έκδοση πρέπει να κάνει:** <3-7 κουκκίδες>
**Δεν κάνει (για τώρα):** <κουκκίδες>
**Δεδομένα:** <χρήματα; προσωπικά; εργαζομένων; πελατών;>
**Χώρα/νόμος:** <π.χ. Ελλάδα, ΕΕ>
**Προϋπολογισμός και χρόνος:** <ό,τι είπε ο χρήστης, αλλιώς «δεν ορίστηκε»>
**Ανοιχτές ερωτήσεις:** <κουκκίδες>
```
